A procedural chocolate-glazed donut renderer implemented in TypeScript. It renders a 1024×1024 PNG with a torus donut, chocolate glaze with angled drips, fried dough texture with noise bump mapping, 90 pastel sprinkle capsules, and a wood table with contact shadow — all in a single dependency-free file run with Node.js.

## Run it

```sh
node main.ts
```
